# Katalon Mobile Automation Project

## Overview

Project ini berisi automation test untuk mobile application menggunakan Katalon Studio. Fokus pada pengujian end to end, regression, dan smoke test untuk memastikan fitur utama berjalan dengan baik di Android dan iOS.

## Tech Stack

* Katalon Studio
* Appium
* Groovy
* Git

## Scope Testing

* UI Testing mobile app samasama
* Functional testing
* End to end user flow
* Smoke dan regression test

## Struktur Project

* Test Cases: berisi skenario test
* Test Suites: kumpulan test cases
* Object Repository: locator element
* Data Files: data testing
* Keywords: custom reusable function
* Reports: hasil eksekusi test

## Cara Menjalankan

1. Buka project di Katalon Studio
2. Pilih Test Suite atau Test Case
3. Klik Run
4. Pilih device atau emulator

## Integrasi

Project ini bisa diintegrasikan dengan:

* CI pipeline seperti Jenkins atau GitHub Actions
* Device farm seperti Kobiton atau BrowserStack

* Gunakan naming test case yang jelas
* Pisahkan test berdasarkan fitur
